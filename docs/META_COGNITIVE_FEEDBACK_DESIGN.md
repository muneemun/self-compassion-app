# 🔭 [설계서] 메타인지 상호작용 피드백 시스템 (Meta-Cognitive Feedback System)

## 1. 피드백 설계 철학 (Core Philosophy)
본 서비스의 시각적/텍스트 피드백은 **'판단(Judgment)과 처방(Prescription)'을 철저히 배제**합니다. 
앱은 사용자의 행위를 칭찬하거나 비난하지 않으며, 오직 입력된 데이터에 따라 **내면 우주의 물리적 구조가 어떻게 변화했는지를 객관적으로 보여주는 '거울'** 역할만 수행합니다.
사용자의 '자기 조율 효능감(Efficacy)'은 앱의 칭찬이 아닌, **나의 개입으로 무질서했던 우주가 안정되는 것을 직접 목격하는 경험**에서 발현됩니다.

---

## 2. 사용자 입력 케이스별 피드백 체계화

### [A. 상태의 관측과 기록]

#### Case 1. 데일리 자아 컨디션 체크인
*   **사용자 입력**: 오늘 나의 기본 에너지 수준(배터리) 기록
*   **시각적 피드백**: 입력된 수치에 비례하여 중앙 태양(Self)의 크기와 발광도가 물리적으로 팽창하거나 축소됨.
*   **메시지 (관망)**: "현재 자아의 코어 에너지가 N%로 관측되었습니다."

#### Case 2. 상호작용(만남) 후 에너지 증감 기록
*   **사용자 입력**: 특정 인맥과의 만남 후, 에너지가 충전되었는지/소진되었는지 기록
*   **시각적 피드백**: 중심 태양과 해당 노드를 잇는 **중력선(Gravity Line)**을 통해 물리적 반응을 보여줌. 에너지를 뺏겼다면 선에 붉은 노이즈가 생기며 맵에 옅은 난기류(Turbulence) 발생. 충전되었다면 선명도가 높아짐.
*   **메시지 (관망)**: "관측 데이터가 궤도에 동기화되었습니다. 태양(자아)의 에너지가 N% 변동했습니다."

---

### [B. 구조의 조작과 통제]

#### Case 3. 물리적 궤도 재배치 (Drag & Drop)
*   **사용자 입력**: 심리적 거리를 두기 위해 인맥 노드를 더 먼 궤도로 드래그하여 이동 (예: Zone 1 -> Zone 4)
*   **시각적 피드백**: 물리적 거리가 멀어짐에 따라 연결선이 느슨하고 희미해짐. 만약 Zone 1에 켜져 있던 **과밀 경고(붉은색 링)**가 있었다면, 이동 즉시 경고가 꺼지고 평온한 색상으로 안정화됨.
*   **메시지 (관망)**: "궤도 재배치가 완료되었습니다. Zone 1의 과밀 상태가 해소되어 구조적 여유가 확보되었습니다."

#### Case 4. 데이터 소멸 (관계 끊기 / 완전 삭제)
*   **사용자 입력**: 더 이상 교류하지 않는 인맥 데이터를 시스템에서 완전 삭제
*   **시각적 피드백**: 중력선이 끊어지며 노드가 우주 밖으로 페이드아웃 됨. 해당 노드가 차지하고 있던 질량(부하)이 사라짐에 따라 태양의 에너지가 미세하게 반등함.
*   **메시지 (관망)**: "해당 객체 데이터가 시스템에서 영구 삭제되었습니다. 전체 궤도 질량이 감소했습니다."

---

### [C. 본질의 발견과 단절]

#### Case 5. 심층 진단(RQS) 완료
*   **사용자 입력**: 특정 인맥에 대한 8문항 심층 진단 테스트 완료
*   **시각적 피드백**: 불투명했던 노드의 껍질이 걷히며 고유의 속성 컬러(예: 뱀파이어는 다크 그레이)와 뱃지가 명확해짐. 맵 상에서 식별 가능한 명확한 데이터 포인트로 전환됨.
*   **메시지 (관망)**: "관계의 물리적 속성 분석이 완료되었습니다. 해당 노드의 상호작용 패턴이 맵에 반영됩니다."

#### Case 6. 외부 중력 차단 (Self-Care 체크인)
*   **사용자 입력**: 타인과의 교류가 아닌, 온전한 나만의 휴식/명상 시간 기록
*   **시각적 피드백**: 화면 내의 모든 외부 노드와 궤도선이 일제히 어두워지고(Focus Dimming), 중심 태양만이 선명하게 박동하며 맵 전체에 부드러운 정화의 파장(Ripple)을 퍼뜨림.
*   **메시지 (관망)**: "외부 중력장의 간섭을 차단했습니다. 시스템이 자아 회복 모드로 전환됩니다."
