# 연락처 동기화(Contact Sync) 기능 개선 및 안정화 기록
**작업일시:** 2026년 5월 6일 ~ 7일
**대상 파일:** `src/features/relationships/RelationshipEntry.tsx`

## 1. 주요 개선 사항 및 신규 기능

### A. 하이브리드 스마트 그룹 필터 도입
* **이슈:** `expo-contacts`의 `getGroupsAsync()` API가 삼성 갤럭시 등 특정 제조사 단말기 커스텀 DB 환경에서 빈 배열(`[]`)을 반환하여 오리지널 그룹 칩이 렌더링되지 않는 문제 발생.
* **해결:** 네이티브 그룹 데이터 조회 실패 시, 앱 자체에서 연락처 메타데이터(회사 필드, 이름 내 가족 키워드 유무, 전화번호 존재 여부)를 분석하여 **가상 스마트 칩(직장/동료, 가족, 번호 있음)**으로 렌더링하는 폴백(Fallback) 하이브리드 로직 구현.

### B. 강력한 한글 초성 검색 엔진 탑재
* **이슈:** 수백 개의 연락처를 검색할 때 타이핑의 번거로움 존재.
* **해결:** 별도의 무거운 외부 라이브러리 없이 유니코드 분해를 통한 자체 초성 추출 함수(`getChosungStr`) 구현. 
* **결과:** 검색창에 'ㄱㄷㅇ' 등 초성만 입력해도 '강동원', '김도영' 등 연관 연락처가 즉시 필터링 되도록 검색 UX 극대화.

### C. UI/UX 간섭 제거 및 터치 영역 최적화
* **이슈:** 리스트 우측의 `[+ 추가]` 버튼이 시각적 노이즈를 유발하고 우측 터치 영역을 낭비함.
* **해결:** `[+]` 버튼을 완전히 제거하고, 연락처 이름과 프로필이 있는 **리스트 행(Row) 전체를 터치 영역(`TouchableOpacity`)으로 확장**. Fat-finger(오터치) 문제를 해결하고 직관적인 추가 경험 제공.

## 2. 롤백 및 제거된 기능 (안정성 확보)

### A. 우측 인덱스 바 (초성/알파벳 퀵 점프) 기능 제거
* **시도:** 화면 우측에 A-Z, ㄱ-ㅎ 퀵 점프 바를 배치하고 `PanResponder`를 도입하여 드래그 스와이프 스크롤 기능 구현 시도.
* **문제 발생:**
  1. 중첩된 스크롤 뷰(`KeyboardAwareScrollView` > `SectionList`) 구조적 한계와 안드로이드 제스처 이벤트 충돌.
  2. 드래그 중 1초에 수십 번 호출되는 `scrollToLocation` 명령으로 인해 UI 애니메이션 큐가 잠기는 Lock-up 현상 및 터치 무시 현상 발생.
* **최종 결정 (안전성 최우선):**
  * 해당 UI/기능은 모든 안드로이드 단말기에서 100% 호환을 보장하기 어려우며, 오작동 시 사용자에게 심한 스트레스를 유발함.
  * 이미 **'초성 검색 엔진'**과 **'스마트 칩'** 필터가 완벽하게 동작하여 탐색에 불편함이 없으므로, 과감하게 인덱스 바 코드를 삭제하여 **안정성과 속도를 최우선으로 확보**함.

## 3. 요약
* 외부 의존도를 낮추고 자체 초성 엔진을 탑재해 가벼우면서도 강력한 연락처 검색망 구축 완료.
* 터치 불량 등 스트레스를 유발하는 불완전한 UI 요소를 배제하고, 핵심인 '검색'과 '클릭'에만 집중하도록 미니멀한 UX 달성.
