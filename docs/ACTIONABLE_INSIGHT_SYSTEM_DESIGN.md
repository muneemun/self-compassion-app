# 📑 [보고서] 자기 효능감 극대화를 위한 관계 구조 통찰 시스템 설계 (v2.0)

## 1. 전체 전략 구조: "Context - Light Input - Visual Reward"
본 서비스의 지속 가능성을 위해 기존의 '설명 중심'에서 '변화 중심'으로 전략을 재구성합니다.

### ① Context 기반 진입 (Context UX)
사용자가 앱을 스스로 찾아오는 것이 아니라, 상황이 앱을 호출하도록 설계합니다.
*   **사람과 만난 직후**: 통화/메시지/회의 종료 시 "지금 이 관계, 나를 채웠나요?" 퀵 체크인 트리거.
*   **잠들기 전**: "오늘 내 태양 상태 확인" 알림을 통한 하루 정서 마감.
*   **감정 급변 순간**: 위젯 또는 퀵 액션을 통한 자발적 진입.

### ② 초경량 입력 + 구조 해석 (Light Input)
입력 구조는 15초 이내에 완료 가능한 "의미 있는 최소값"으로 설계합니다.
*   **교류(Interaction) 축**: 관계 기반 입력 (소모됨 🔴 / 중립 ⚪ / 채워짐 🟢).
*   **나를 위한 행동(Self Action) 축**: 회복 기반 입력 (산책, 휴식, 취미 등 행동 + 효과 3단계).

### ③ 즉시 상태 변화 보상 (Visual Reward)
"좋아졌다"는 텍스트 대신 "눈으로 보이는 변화"를 통해 즉각적인 효능감을 제공합니다.
*   **소모 관계 입력 시**: 태양(L0)의 밝기 감소, 표면이 거칠어짐. 해당 관계 노드의 붉은 왜곡 및 궤도 흔들림.
*   **회복 행동 입력 시**: 태양 표면의 매끈한 변화, 주변 공간의 노이즈 감소 및 안정화 파동 연출.

## 2. 해석 UX: 텍스트의 최소화 (Interpretive UX)
긴 설명과 감정 코칭을 배제하고 **"한 문장 + 시각적 해석"**으로 직관적인 깨달음을 줍니다.
*   **인사이트 예시**: "지금 소모는 특정 관계에서 집중적으로 발생 중입니다.", "최근 3일간 회복 자원 접촉이 부족한 상태입니다."
*   **시각적 강조**: 문제 관계를 강조하거나, 궤도를 왜곡시켜 구조적 원인을 즉시 이해시킴.

## 3. "자아 가치 보호"를 위한 시스템 표현
*   **태양의 항상성**: 어떤 부정적 관계가 입력되어도 태양의 **Core(핵심)**는 파괴되지 않고 유지됨을 시각적으로 보여주어 자아의 안전성을 보장함.
*   **분리 효과(Detachment)**: 문제 관계를 외곽으로 밀어내거나 연결선을 흐릿하게 처리하여 정서적 거리감을 시각화함.
*   **분리 버튼**: "이 관계와 나를 분리하기" 버튼 클릭 시 즉각적인 영향력 감소 연출.

## 4. 3단계 보상 리듬 (Reward Cycle)
1.  **매일 (즉시)**: 태양과 우주의 시각적 상태 변화 (감각적 보상).
2.  **단기 (3~5일)**: "이 관계가 반복적 소모를 유도함"과 같은 패턴 인식 (인지적 보상).
3.  **주간 (7일)**: "구조적 원인 때문에 힘듦"을 깨닫게 하는 심층 분석 (통찰적 보상).

## 5. 3대 뷰 시스템 (Focus / Balance / Dynamics)
사용자의 상황과 필요에 따라 정보를 선별적으로 제공하여 인지 부하를 줄이고 효능감을 높입니다.

### ① Focus View (핵심 집중 모드)
*   **목적**: 빠른 상황 판단 및 즉각적 행동 결정 (Home 기본값).
*   **시각화**: 태양 + Top 10~20개 관계만 개별 노드 표시. 나머지는 '밀도 구름(Halo/Dust)'으로 축약.
*   **효과**: 150명 이상의 인맥 속에서도 결정 피로를 방지하고 핵심 관계에만 집중하게 함.

### ② Balance View (구조 균형 모드)
*   **목적**: 관계 생태계의 전체적인 건강도 및 패턴 파악.
*   **시각화**: 궤도별 밀도/색상 히트맵. 개별 노드는 아이콘화하여 축약. 궤도 링에 용량 가이드 표시.
*   **효과**: 어느 영역이 과밀하거나 소모적인지 구조적으로 즉시 이해하게 함.

### ③ Dynamics View (변화 흐름 모드)
*   **목적**: 입력에 대한 드라마틱한 체감 보상 강화.
*   **시각화**: 최근 72시간 기준 에너지 흐름선(Flow Line) 표시. 태양 표면의 실시간 박동 및 질감 변화.
*   **효과**: 내 행동이 정서 우주를 어떻게 변화시켰는지 시각적으로 목격하게 함.

## 6. 공통 UX 규칙 및 성능 전략
*   **스와이프 전환**: 3가지 모드 간 부드러운 스와이프 전환 및 상단 인디케이터 제공.
*   **태양의 고정**: 자아 가치 보호를 위해 태양(L0)은 항상 중심에 고정.
*   **LOD(Level of Detail)**: 한 화면의 개별 노드 수를 30개 이하로 제한하여 성능 및 가독성 확보.
*   **항상 노출**: 한 문장 인사이트와 액션 버튼은 어떤 뷰에서도 최하단에 고정됨.
