# 🎯 1:1 집중 조율 알고리즘 명세 (Focus Tournament Logic)

본 문서는 `FocusTournament.tsx`에서 수행되는 사용자의 관계 선택 패턴 분석 알고리즘과 그에 따른 피드백 생성 로직을 정의합니다.

## 1. 개요
'1:1 집중 조율'은 사용자가 선택한 인맥들 중 무의식적으로 더 중요하게 생각하는 대상을 토너먼트 방식으로 추려내는 과정입니다. 알고리즘은 **진입 맥락(Entry Lens)**과 **결과 데이터(Winner's Zone)**를 결합하여 현재 사용자의 심리적 관계 지향성을 분석합니다.

---

## 2. 분석 1단계: 진입 맥락(Entry Lens) 분석
토너먼트 시작 시 선택된 '렌즈'에 따라 가중치와 우선 분석 순위가 결정됩니다.

| 진입 렌즈 (Lens) | 분석 패턴 (Lean Type) | 인사이트 핵심 키워드 | 설명 |
| :--- | :--- | :--- | :--- |
| **Negative (에너지 포식자)** | **Boundaries (경계)** | 심리적 방어선, 거리두기 | 소모적인 관계들 사이에서 자신을 지키기 위한 선택을 강조 |
| **Frequency (일상의 중력)** | **Efficiency (정제)** | 시간의 밀도, 교감의 질 | 물리적 접촉 빈도보다 정서적 교감의 의미를 재평가 |
| **None / Positive** | (데이터 분석 단계로 이행) | - | 일반적인 조율 상황으로, 승자들의 구역 분포를 분석함 |

---

## 3. 분석 2단계: 승자 데이터(Zone Distribution) 분석
진입 맥락이 특수하지 않은 경우, 최종 승자들의 **오빗 존(Orbit Zone)** 분포를 분석합니다.

### 3.1 판별 기준 (Trigger)
- **집중 패턴**: 최종 승자 중 특정 Zone에 속한 인원이 **70% 이상**일 때 발동.
- **분산 패턴**: 특정 Zone의 비중이 70% 미만이고 고르게 분포된 경우 발동.

### 3.2 패턴별 상세 정의
| 패턴 명칭 | 주요 Zone | 라벨 | 핵심 인사이트 내용 |
| :--- | :---: | :--- | :--- |
| **Stability** | Zone 1 | **안정** | 새로운 자극보다 나를 지탱하는 [깊은 안정감]과 핵심 그룹 방어 무의식 |
| **Growth** | Zone 2 | **성장** | 가치관을 공유하는 정서적 공유 그룹과의 교감 및 [성장] 지향성 |
| **Vitality** | Zone 3 | **활력** | 명확한 [목표와 활력]을 주는 기능적 협력 관계에 집중된 상태 |
| **Expansion** | Zone 4, 5 | **확장** | 익숙함보다 [새로운 연결과 외연]에 민감하게 반응하는 확장 욕구 |
| **Harmony** | (분산) | **균형** | 각기 다른 역할의 관계들 사이에서 치우치지 않는 [조화로운 균형] |

## 4. UI/UX 시각화 정보
분석된 패턴에 따라 결과 화면의 테마 색상과 아이콘이 동적으로 변경됩니다.

- **Stability (안정)**: `#4A5D4E` (짙은 녹색), `Shield` 아이콘
- **Growth (성장)**: `#D98B73` (코랄), `TrendingUp` 아이콘
- **Vitality (활력)**: `colors.accent` (바이탈 황색), `Zap` 아이콘
- **Boundaries (경계)**: `#737874` (회색), `Shield` 아이콘
- **Efficiency (정제)**: `#6B8E23` (올리브), `History` 아이콘
- **Expansion (확장)**: `#C0C0C0` (실버), `Sparkles` 아이콘
- **Harmony (균형)**: `colors.primary` (메인 테마), `Heart` 아이콘

## 5. 데이터 활용 가이드
본 분석 결과는 `onComplete` 콜백을 통해 상위 컴포넌트로 전달되며, 사용자의 '정서 건강 리포트' 내 **[관계 지향성 지점]**을 업데이트하는 기초 데이터로 활용됩니다.
